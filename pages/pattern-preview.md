## How to Use This Preview

1. **Edit colors** in `_sass/_01_settings_colors.scss`
2. **Edit patterns** in `_sass/_07_layout.scss`
3. **Save the file** - Jekyll auto-regenerates
4. **Refresh this page** - See changes instantly
5. **Test on actual pages** - Apply patterns to pages using `pattern_class`

## Quick Pattern Testing

To test a pattern on this page temporarily, add this to the front matter:

```yaml
header:
  pattern_class: pattern-rugby
```
